# Cartelera pastoral pública

Sitio estático para GitHub Pages. Publica únicamente horarios y actividades marcadas como públicas.

## Actualizar la cartelera

1. En la aplicación privada, pulsa **Exportar cartelera**.
2. Sustituye `cartelera-data.json` por el archivo descargado.
3. Confirma y sube el cambio al repositorio.

Nunca subas `corrales-pastorales.json`: contiene información pastoral privada.
